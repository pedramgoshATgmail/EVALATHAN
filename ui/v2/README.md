# Evalathan UI/UX v2

Local three-column shell (SEISMO-inspired): engines left, evals center, **PAST RUNS** right.

## Open in a browser

From this folder:

```bat
python -m http.server 8787
```

Then open http://127.0.0.1:8787/

Or open `index.html` directly (folder browse works best via the HTTP server).

## Themes

White / Grey / Black (bottom-left). White body text uses Granite Gray (`#676767`), not pure black.

## Slotbox

Wording fixed: *Paste a GitHub link, or a folder on this PC. Then press Evaluate.* Buttons: **Browse folder**, **Evaluate**.
