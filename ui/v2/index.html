Session timer - FUSS

FUSS stands for For-User Session Switch. FUSS is a utility timer, not an agent. You use it to time your sitting with AI. It is not medical advice.

  1. Tick the box to confirm you are only setting a timer.
  2. Choose a duration in minutes (5 to 45; 25 is typical).
  3. Press Start timer.
  4. The popup counts 3-2-1-0, then closes while the sitting runs.
  5. Press Stop timer if you finish early.
