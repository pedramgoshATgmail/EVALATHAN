# Evalathan BUILDLOG

Past, current, and next. This is the product roadmap, not a diary.

## Past - v0.2

Hydra conducts sixteen software and agentic evalers on a local folder. The laptop scan grades only what is on disk. A blank is not a fail and not a zero. The sixteen stay sixteen. Public coding exams (SWE-bench, PRDBench, Ragas catalogs) sit on [Trajectly](../GLOSSARY.md#user-content-trajectly)'s exam shelf and are not run.

## Past - v0.3

First of two 4IR (Fourth Industrial Revolution) eval paradigms. Shipped Nov 1 2026 as a local runner.

- Manifesto direction: *Until Artificial Intelligence Independently Eurekas on its own*. Pedram Goshtasbpour will release that follow-up paper and put it up for peer review in early 2027, thirty years after Jim Highsmith's [Messy, Exciting, and Anxiety-Ridden: Adaptive Software Development](https://web.archive.org/web/20171004140236/http://www.adaptivesd.com/articles/messy.htm) (American Programmer, 1997; also [Adaptive Software Development](https://en.wikipedia.org/wiki/Adaptive_software_development)). Highsmith's second world was unpredictable, nonlinear, and fast. PRETRUWs states a third world. The follow-up does not replace Highsmith.
- Paradigm: **[PRETRUWs](../GLOSSARY.md#user-content-pretruws)** (PREdiscovery TRuncated-Universes and Worlds).
- Methodology framework: **[LuDaTs](../GLOSSARY.md#user-content-ludats)** (Limited-universe Data Test sets) is a subset of PRETRUWs. Dehydrus conducts eight LuDaTs evalers, not eight PRETRUWs evalers. Each brand has its own methodstack.
- Conductor / router: **[Dehydrus](../GLOSSARY.md#user-content-dehydrus)**. Window title DEHYDRUS. Command `evalathan dehydrus`. He is not an eighteenth Hydra score.
- Full desk ships all eight brands: Copernly, Keplerly, Galileoly, Darwinly, Mendly, Einsteinly, CurCuriely, Newtonly. CurCuriely is the pair world (Marie Curie and Pierre Curie; two agents). Newtonly is on the desk and deferred to v2 until Keplerly and Galileoly both show a sealed world.
- v0.3 names a sealed world file. It does not pretend a prompt cutoff is 1610. ExAnte (ACL 2026 / EACL) showed large language models leak past a stated cutoff.
- [HabTwin](../GLOSSARY.md#user-content-habtwin) asks whether a stand-in keeps predicting what the real person or the real machine would do, in a safe lab, more than once. v0.3 does not run that exam yet. Dehydrus only looks for a lab file. If none is there, it prints `No HabTwin lab trace`. HabTwin is not one of the eight LuDaTs evalers.
- Default Hydra UI in v0.3 was still the Tk desk. README install blocks were clone-only, so a folder already on disk stayed stale.

## Current - v0.3.1

Shipped Nov 19 2026. Same Hydra sixteen + Dehydrus eight. New default **browser desk**, plus clone-or-update install path.

- `launch.bat` / `launch.sh` open `http://127.0.0.1:8787/` (`ui/v2` via `evalathan.webdesk`), not the old Tk HYDRA window.
- Evaluate on the desk calls the real Hydra path: `prepare()` then `conduct()` for all sixteen evalers. Memo lines are cell summaries (measured / deferred / passed), not mock `/100` scores.
- README CMD / PowerShell / Mac install blocks **clone if missing, else always `git fetch` + `git checkout main` + `git reset --hard origin/main`**, so an old Tk Hydra folder is replaced by the published browser desk every paste.
- Launchers do the same hard-reset on each start when the folder is a git clone, then re-enter once so the newly pulled launcher runs.
- `git reset --hard` discards local edits inside `evalathan-program` on purpose: published desk wins.
- Dehydrus stays a second command: `evalathan dehydrus`.
